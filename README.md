# Projeto SQL – Mini-mundo

## Criação e Manipulação de Dados com SQL

Este projeto tem como objetivo implementar e manipular dados em um banco de dados relacional utilizando a linguagem SQL (DML), aplicando conceitos de tipos de dados e boas práticas de versionamento e compartilhamento de código.

## Objetivos de Aprendizagem

### Taxonomia de Bloom
- Aplicar: Execução de comandos SQL para manipulação de dados reais.
- Criar: Desenvolvimento de scripts SQL completos e funcionais.

### Taxonomia de Fink
- Aplicação: Uso de ferramentas como MySQL Workbench ou PGAdmin.
- Integração: Uso de modelagem lógica, normalização e integridade de dados.
- Aprendendo a aprender: Tratamento de erros e interpretação de mensagens do sistema.

## Estrutura do Banco de Dados
O banco de dados simula um sistema de biblioteca, contendo as seguintes entidades:
- Usuario
- Livro
- Emprestimo

## Tecnologias Utilizadas
- SQL
- MySQL / PostgreSQL
- GitHub
